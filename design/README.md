# Navio 设计参考

`navio-beta7-approved.html` 保存了 Public Beta 7 开发前用户认可的交互预览，用于后续界面讨论和实现对照。它是独立的设计参考，不是正式客户端，也不是功能完成情况的证明。

用浏览器打开 HTML 文件即可查看。页面包含主题、导航、连接、节点、用量、日志、网络信息和账号等流程；连接状态、流量、延迟、账号、订阅与操作结果都是模拟数据。交互只保留在当前页面内，刷新后重置。请勿在演示表单中填写真实密码、验证码、订阅或节点凭据。

## 与正式版本的关系

- 正式客户端源码位于 `src/`；实际发布范围和验证边界见根目录 `README.md`、`CHANGELOG.md` 和 `Navio-验证记录.txt`。
- 预览包含部分尚未接入正式客户端的方案，例如连接的应用／网站／逐条三视图，以及用量的今日／本周／本月／自选日期、保存期限设置。不能据此认定这些功能已在 Public Beta 7 发布。
- 预览中的网络、系统设置、账号、备份、更新和管理员相关操作只演示交互，不连接 Mihomo、D.E.X 平台或真实供应商，不执行系统命令。
- 后续修改应同时核对已确认需求与正式源码。保留原有能力，不能直接用模拟逻辑替换生产实现。

## 独立副本处理

此副本保留原有布局和交互，没有对整份 HTML 重新排版。为便于在浏览器中独立查看，移除了原预览的宿主状态读写桥接和远程字体加载；字标使用原样式已有的系统字体回退，因此字体外观可能略有不同。图片与图形资源随文件内嵌，预览不发送网络请求或上传表单内容。

该目录不包含完整聊天、用户截图、生产配置、账号数据或服务器部署文件。HTML 是设计快照，不参与客户端构建和发布打包。
