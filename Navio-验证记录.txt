Navio 0.6.0-beta.2 · Public Beta（公测版）验证记录

本轮修复
- 复现多个配置检查共用 test 目录下载 GeoIP 时的 Windows 文件占用报错。下载中的半文件被另一个检查判为损坏并尝试删除。
- 相同目录的配置检查排队；准备、执行和成功缓存全过程持有目录锁。超时或取消会等待子进程关闭后再释放锁。
- 检查前备份残缺 MMDB，优先复用完整本地数据；检查成功后只缓存缺失资源，不重命名、删除或覆盖运行目录的已有文件。
- 显式下载先校验全部响应的大小、长度和 MMDB/ASN 尾部元数据，再提交。内核运行时使用原有内核数据更新功能，避免替换占用文件。
- 简易模式候选配置改在独立校验目录运行；本地文件提供者仍读取原路径，HTTP 校验缓存留在 test 中，正式配置保持原样。
- 未新增依赖，未改变固定内核、账号流程或订阅配置。

本轮验证
- Windows 单元测试：61 个文件，760 项通过，1 项跳过。排除 POSIX/Linux 专用的 src/main/utils/app-info/linux.test.ts，不宣称 Linux 实机验收通过。
- 全项目 format:check、lint:check、typecheck 检查通过；ESLint 保留 31 项既有警告、0 项错误。
- electron-vite 主进程、preload、界面生产构建通过。
- 使用真实固定 Mihomo 内核及回环 HTTP 服务复现旧问题；修复后的两个并发检查仅下载一次，均通过，完整文件 SHA256 一致。
- 使用真实内核验证残缺校验数据库备份、本地完整数据复用、成功后缓存。测试仅执行 -t，不启动代理或 TUN，不读取用户订阅。
- 分发包不包含测试数据库、用户账号、会话或订阅资料，不打包历史 GeoIP / ASN / GeoSite 数据。

验证边界
- MMDB 尾部检查用于拦截下载残片和明显错误响应；完整数据库格式仍由内核校验，不宣称实现完整 MMDB/DAT 解析。
- 本轮验证范围为配置检查和资源文件修复，没有将旧版真实流量测试自动算作本版验收。
- 正式邮件、短信、Google/GitHub 提供商及账号服务器仍需部署配置与实测；本轮没有修改线上 DNS/Caddy。
- 独立 Windows TUN 后台服务尚未实现；提权 TUN、外部代理线路、完整协议组合、代码签名、自动安装及 macOS/Linux 不在本次通过范围内。
