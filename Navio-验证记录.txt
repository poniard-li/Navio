Navio Release 1.0.0 · Public Beta 6 验证记录

变更范围
- 安装版与免安装版在线更新；服务端分别管理 EXE 与 ZIP。
- 可选 Windows TUN 后台服务、按次管理员运行及独立卸载入口。
- 节点异常推荐、逐项订阅冲突处理、外部引用文件备份与恢复。
- 图片/视频主题、离线资源、完整主题包，以及下架作品修改复核。
- 同机账号继续登录、管理员协助恢复、旧盲盒账号主动绑定。

检查结果
- Windows 客户端测试 884 项通过、1 项跳过；Linux 专用符号链接测试未在 Windows 套件运行。
- 平台测试 196 项通过；旧服务账号适配器 6 项测试通过。
- Windows 打包检查 10 项通过，包括空间不足、文件缺失、损坏和复制失败。
- 更新辅助程序在隔离目录验证正常替换、校验失败、替换失败和启动失败回退，原配置保留。
- 账号入口、双账号验证弹窗、后台恢复表单和主题编辑器已用模拟数据检查布局与入口。

验证范围
- 本轮没有修改真实账号、发送验证码、重新授权第三方登录或部署服务器。
- 未执行真实 Windows 安装、升级、卸载、UAC 授权或 TUN 服务安装。系统服务、真实线路及安装器升级仍需在目标机器验收。
- 免安装更新可在目录替换和程序启动失败时尝试回退；安装版写盘阶段异常不具备完整目录回滚，用户配置保留。
- 服务模式拒绝自定义入站 listeners、外部控制面板和不受支持的文件引用；可选择按次管理员运行方式使用这些配置。
- 旧盲盒桌面客户端源码尚未取得。本版提供 Navio 绑定界面、平台接口和私有旧服务适配器，不代表原客户端已具备统一账号入口。
- 新账号和主题功能需 D.E.X Platform 0.7.0-beta.5；当前生产服务需按部署说明升级。

以下为此前版本记录。

Navio 0.6.0-beta.5 · Public Beta（公测版）验证记录

变更范围
- 在设置→账号中增加邮箱、手机号解绑；Google / GitHub 解绑增加身份验证。
- 支持使用当前密码或已绑定联系方式的验证码；保留最后一种联系方式。

- 账号服务需先升级到 D.E.X Platform 0.7.0-beta.4。

检查结果
- 账号相关测试90项通过，包括凭据传递、缓存刷新、会话退出和旧请求晚到。
- TypeScript检查、修改文件的格式与静态检查通过。
- 完整客户端测试：830项通过、1项跳过；另1项Linux符号链接测试因Windows权限限制失败。
- 未操作真实账号的解绑或删除；邮件、短信和第三方服务未在本轮重新发送或授权。

Navio 0.6.0-beta.4 · Public Beta（公测版）验证记录

变更范围
- 增加独立的托盘状态图标和状态提示，区分系统代理、TUN 与内核异常。
- 修复临时盘空间不足时，安装文件不完整却显示成功的问题。
- 安装前检查临时盘与目标盘空间，解压后及复制后校验程序文件。
- 升级前先验证完整安装文件，再替换旧程序。

检查结果
- 已确认原故障：安装后的主程序被截断，缺少其余程序文件；补齐并校验文件后，用户确认可以正常打开。
- 完整主程序通过 Windows 原生映像检查；截断文件返回错误 193。
- 格式、静态检查与 TypeScript 检查通过。
- 主进程、preload 和界面生产构建通过。
- 安装包与免安装包的主程序及 app.asar 一致；仅免安装包包含 PORTABLE 标记。
- 安装包以当前用户权限安装，拒绝覆盖便携目录；安装和卸载均要求先正常退出 Navio。
- 分发包不包含用户数据、测试数据库或历史 GeoIP / ASN / GeoSite 数据。

验证范围
- 安装检查覆盖空间预算、文件缺失和内容损坏；未在本机执行新版安装、升级或卸载。完整安装流程仍需在独立 Windows 环境中验证。
- 邮件、短信、Google/GitHub 和账号服务器仍需完成部署配置与实测。
- 独立 Windows TUN 后台服务尚未实现；提权 TUN、真实代理线路、完整协议组合及 macOS/Linux 不在本次验证范围内。
