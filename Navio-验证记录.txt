Navio Release 1.0.0 · Public Beta 7 验证记录

变更范围
- 概览、代理组、工作区导航、独立账号页与 Ctrl+K 快捷操作。
- 24 套官方主题、8 种动态场景、整窗试用、独立材质与动效策略。
- 国内应用全局例外预设，日志暂停、导出、诊断与敏感字段隐藏。

检查结果

- Windows 打包安全检查 10 项通过；服务宿主策略检查 70 项通过。
- 隔离数据下启动正式程序，使用本地账号服务登录、导入配置并通过真实 Mihomo 内核转发本地请求。
- 全局例外直连、其余流量拒绝及恢复规则路由均通过；19 个功能页面无脚本错误。
- 24 套官方主题包通过校验并完成跨页试用、恢复；保留主题、材质弹窗和快捷操作面板可用。
- 简易与标准模式使用同一订阅；800×600 窗口无横向页面溢出。
- 本地账号服务断开后仍可离线使用。测试前后 Windows 系统代理注册表一致。

验证范围
- 主题烟测使用经过校验的本地资源缓存；官方资源上线后仍需能够访问 GitHub 下载地址。

- 安装器沿用已验证的空间预检和复制校验；未执行 Windows 安装器界面、系统注册与卸载全流程。
- 玻璃效果作用于 Navio 窗口内部；系统高对比和减少动态效果设置优先。

Navio Release 1.0.0 · Public Beta 6 验证记录

- 平台测试 196 项通过；旧服务账号适配器 6 项测试通过。
- Windows 打包检查 10 项通过，包括空间不足、文件缺失、损坏和复制失败。
- 更新辅助程序在隔离目录验证正常替换、校验失败、替换失败和启动失败回退，原配置保留。
- 账号入口、双账号验证弹窗、后台恢复表单和主题编辑器已用模拟数据检查布局与入口。

验证范围
- 本轮没有修改真实账号、发送验证码、重新授权第三方登录或部署服务器。
- 未执行真实 Windows 安装、升级、卸载、UAC 授权或 TUN 服务安装。系统服务、真实线路及安装器升级仍需在目标机器验收。

- 服务模式拒绝自定义入站 listeners、外部控制面板和不受支持的文件引用；可选择按次管理员运行方式使用这些配置。

- 新账号和主题功能需 D.E.X Platform 0.7.0-beta.5；当前生产服务需按部署说明升级。
