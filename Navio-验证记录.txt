Navio 0.6.0-beta.1 · Public Beta（公测版）验证记录

本轮代码验证
- 主进程与界面 TypeScript 检查通过。
- 账号、主题和下载单元测试：5 个文件，81 项通过。覆盖原有离线/会话撤销边界、软件内登录/重置密码、固定 API 操作映射、凭据加密保存、OAuth 同源启动/取消/补充注册、云主题内容校验与本地 ID 隔离，以及 GitHub HTTPS 下载跳转。
- 全项目 format:check、lint:check、typecheck 三项提交前检查通过；ESLint 有 31 项既有警告、0 项错误。
- Windows 全量单元测试：58 个文件，730 项通过，1 项跳过。明确排除 POSIX/Linux 专用的 src/main/utils/app-info/linux.test.ts，不宣称 Linux 平台验收通过。
- electron-vite 主进程、preload、界面生产构建通过。
- 本轮没有新增依赖，没有改动固定内核、sidecar 或用户数据。

本轮变化
- 公开包外置全部历史 Geo 数据，新增独立的一键 HTTPS 下载入口；数据缺失检查、下载失败/大小/页面误返回防护与系统代理启动顺序新增 8 项测试。
- 密码/验证码登录、注册、找回密码与日常账号管理改为软件内操作；令牌由主进程保存，不返回界面。
- Google/GitHub 保留系统浏览器第三方授权，账号补充资料与绑定管理回到软件内完成。
- 在线主题搜索、收藏、举报和自己发布的主题管理不再依赖网页账号门户。
- 默认账号 API 为 navio.mydex.top；更新页面为 GitHub Releases，公测更新 channel 为 beta。

验证边界
- 上述单元测试使用隔离目录与模拟网络/系统安全存储，不等于正式服务商端验收。
- 本记录不将上一版的实机与流量测试自动算作 0.6 的完整复测。最新打包启动、真实本地服务联调及界面检查应以本次发布的补充验收结果为准。
- 正式邮件、短信、Google/GitHub 凭据尚需在部署服务器配置并实测；本轮没有修改线上 DNS/Caddy，也没有发布网站。
- 独立 Windows TUN 后台服务尚未实现；提权 TUN、真实订阅质量、完整协议组合、代码签名、自动安装、macOS/Linux 不在本次通过范围内。
- 测试账号、会话和数据库不得包含在程序包或源码包中。
