D.E.X STUDIO 0.1.0 — 本地验证版

这是以独立 Clash 内核驱动的新桌面外壳。D.E.X STUDIO 负责界面、操作流程和主题系统；底层代理与规则路由仍由 Clash 完成。本版本不需要注册或登录账号，也不提供代理节点或订阅服务。

开始使用
1. 在最终便携应用目录中启动 D.E.X STUDIO.exe。保留同目录的 resources 等配套文件，不要只复制单个 EXE。
2. 导入本地 .yaml/.yml 文件，或者输入直接返回 Clash YAML 的 HTTPS 订阅链接。
3. 选择配置并启动内核，再按需开启“系统代理”。仅启动内核不会自动开启系统代理。
4. 在代理节点页面选择代理组/节点；可切换规则、全局、直连模式，并查看连接、流量与日志。
5. 正常关闭应用会停止其内核，并尝试恢复由本应用接管的系统代理设置。

源代码运行入口
源码根目录包含 package.json，启动命令为 pnpm start；依赖缺失时先执行 pnpm install。打包入口为 pnpm run package。源码运行需要本机 Node.js 与对应包管理器环境，便携应用无需使用这些命令。

订阅格式与兼容性
仅接受 HTTPS 的标准 Clash YAML；不接受登录网页、Base64 节点列表或其他客户端的专属链接。单个配置最大 10 MiB。本首版不运行订阅中的脚本，不读取配置指定的本地 provider 文件；远程 provider 需使用 HTTPS。旧 Clash 核心不保证兼容后续其他分支新增的协议或字段。

端口与数据
代理混合端口：127.0.0.1:17890（HTTP/SOCKS）。
本机控制接口：127.0.0.1:19090，使用运行时生成的随机密钥。
这些端口被占用时，应用会提示错误，不会关闭占用端口的其他程序。
默认应用数据：%APPDATA%\DEX-STUDIO。
配置、订阅地址、主题与运行状态保存在该独立目录。订阅地址可能包含访问凭据，请不要将整个数据目录公开发送。
本应用不修改原 Clash for Windows 的安装文件或配置目录。Windows 系统代理是系统共用设置；开启本应用的系统代理会更改当前用户的代理设置，因此不要同时让多个代理客户端争抢该开关。

主题
内置主题与本地主题导入/导出不依赖账号。主题文件使用受校验的 JSON 数据格式。
远程主题库目前待部署；未部署并设置正确地址前，不能将远端浏览/发布视为已上线功能。服务器部署包应由具有可信 SSH 连接的用户终端执行，具体见随附主题库部署说明。发布主题需要服务器颁发的发布令牌，普通本地使用不需要令牌。

当前范围
这是普通用户态代理首版，不包含 TUN、Windows 服务模式、驱动安装、自动启动后台代理、账号登录后端或付费订阅后端。不开启内核和系统代理时，界面展示实际未连接状态。
核心和 GeoIP 的来源与再分发注意事项见 resources\THIRD-PARTY-NOTICES.txt。
