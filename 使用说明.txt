D.E.X STUDIO 0.2.0 — Windows 本地验证版

D.E.X STUDIO 提供独立设计的界面、操作流程和主题系统，代理与规则路由仍由原 Clash 内核完成。无需注册账号，不提供代理节点或订阅服务。

开始使用
1. 解压整个便携包，启动 D.E.X STUDIO.exe。保留 resources 等配套文件，不要只复制 EXE。
2. 在“连接”页面添加 Clash YAML 的 HTTPS 订阅链接，也可导入本地 .yaml/.yml 文件。
3. 点击“连接”：自动启动内核并开启 Windows 当前用户的系统代理；“断开连接”会尝试恢复之前的代理设置并停止内核。设置中仍可单独控制内核与系统代理。
4. 点击首页当前线路即可搜索与切换；节点页提供策略组、收藏、搜索、排序和批量延迟测试。自动策略组由内核选择线路，不能手动指定。
5. 正常退出会等待恢复系统代理；如恢复失败，窗口保留并提示重试。最小化后可通过系统托盘恢复窗口、连接或退出。

0.2.0 体验更新
浅色冰川白、深色石墨黑加入内置主题，共六套。外观页一键选用；设计主题时配色与圆角实时预览，支持保存后应用、导入、导出和主题发布。
主要导航简化为连接、节点、订阅、外观；网络活动、规则、日志置于高级入口。
连接状态同时检查内核与系统代理；仅启动内核不会显示“已连接”。这不等同于外网线路可达性检测，线路是否可用仍应结合延迟测试与实际访问确认。
Ctrl+K 搜索操作，方向键选择，Enter 打开，Esc 关闭。
Ctrl+Enter 连接/断开，Ctrl+1…7 切换页面，Ctrl+, 打开设置。
搜索节点时，后台刷新保留输入与焦点；收藏保存在本机。

订阅格式
支持 HTTPS 标准 Clash YAML，最大10 MiB。不支持登录网页、Base64 节点列表或其他客户端专属协议；不执行订阅脚本；远程 provider 使用 HTTPS，本地 provider 文件不载入。保留的旧内核不保证支持其他分支后续新增的协议。

数据与端口
数据目录：%APPDATA%\DEX-STUDIO，可从设置打开。
混合代理入口：127.0.0.1:17890；控制接口：127.0.0.1:19090，随机密钥认证。
端口占用时会提示，不终止其他进程。订阅地址可能含凭据，不要公开整个数据目录。
Windows 系统代理为当前用户共用设置，避免多个代理客户端同时修改。
原 Clash for Windows 安装文件与配置目录不修改。

主题服务
内置与本地主题无需账号。在线主题库仍需在你的服务器执行随附部署脚本并填写 API 地址；发布使用独立令牌。主题服务只传输设计数据，不上传代理订阅与配置。

当前范围
支持系统代理；TUN、Windows 服务模式、账号系统、自动更新和代码签名尚未接入。来源与再分发说明见 resources\THIRD-PARTY-NOTICES.txt。

开发
源码目录运行 pnpm install、pnpm start；pnpm run package 构建 Windows 便携版。便携包使用者无需安装 Node.js。

验证
后端自动化测试、真实 Clash 内核启停/模式/线路、本机 HTTP 代理转发、真实 Electron 界面、主题设计、键盘搜索、1050×700 布局均已检查。系统代理写入/恢复使用模拟适配器测试；未更改用户真实系统代理，未使用用户私人订阅验证外网。在线服务器尚未部署。
