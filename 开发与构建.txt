D.E.X STUDIO 源码入口

环境：Windows x64，Node.js 24 LTS，npm 或 pnpm。

安装和启动（在本文件所在目录打开终端）：
  npm install
  node node_modules/electron/install.js
  npm start

GitHub 下载较慢时，可在当前 PowerShell 会话中使用 Electron 文档列出的镜像：
  $env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'
  node node_modules/electron/install.js
安装器仍使用 npm 包内的发布校验和验证二进制。

运行测试：
  npm test

运行真实内核测试（使用临时 DIRECT-only 配置，不写真实系统代理）：
  $env:DEX_RUN_REAL_CORE_TEST='1'
  node --test test/backend-integration.cjs
  Remove-Item Env:DEX_RUN_REAL_CORE_TEST

构建 Windows 便携版：
  npm run package

程序结构：
  renderer/    全新 D.E.X 界面、交互和主题编辑器
  electron/    主进程、受限 IPC、内核生命周期和主题服务
  shared/      主题格式校验及内置主题
  server/      可独立部署的主题库 API、Docker 配置和安装脚本
  resources/   来自用户档案的 Clash 内核、GeoIP、品牌图标与来源记录
  test/        后端、系统代理恢复逻辑和主题服务测试

核心端口、数据目录与接口 token 由主进程管理，不暴露给远程主题。
桌面渲染器使用 contextIsolation、sandbox 和受限 IPC。
参考：https://www.electronjs.org/docs/latest/tutorial/security
安装参考：https://www.electronjs.org/docs/latest/tutorial/installation

当前没有自动更新或代码签名配置。发布新版本需先完成第三方组件许可核对、
发行签名及用户使用环境验证。server/.env 与应用数据目录不得打入发行包。
