# Navio 0.5.0-preview.1

Built by D.E.X Studio · Windows x64 免安装调试版 · 2026-11-11

这次交付包含 Navio 客户端、D.E.X 统一账号与管理后台、产品总站、Navio 介绍下载页和账号门户。服务器文件已制作；阿里云部署与正式邮件、短信、Google/GitHub 接入仍需在服务器完成，不能将本地测试视为已经上线。

## 文件

- `Navio-v0.5.0-preview.1-Windows-x64.zip`：解压整个目录后启动 `Navio.exe`，不要只移动 exe。
- `Navio-v0.5.0-preview.1-source.zip`：对应客户端源码、锁文件、构建说明和上游许可证。
- `DEX-Platform-v0.5.0-preview.1.tar.gz`：独立服务器与网站源码部署包，顶层为 `dex-platform/`。
- `Navio-v0.5-SHA256.txt`：三个归档的校验值。
- `dex-platform/deploy/部署指南.md`：完整阿里云部署、DNS、管理员、登录提供商、下载发布、备份和回滚步骤。

## 先部署账号服务，再使用客户端

首次使用需要 D.E.X 账号。客户端打开账号门户，在浏览器中登录并核对设备代码后授权；已有设备在账号服务器暂时不可用时可继续离线使用本机代理、配置和已下载主题。

默认账号地址为 `https://account.mydex.top`。目前部署尚未完成时无法向这个地址注册。服务器所有者可先用部署指南中的交互命令创建第一个管理员，以用户名和密码登录，完成调试，无需先配置 SMTP。普通新用户注册需要至少一个实际可用的联系方式验证服务。

Navio 账号不提供代理线路。订阅链接仍由用户自行导入；D.E.X 官方服务不备份订阅链接和节点凭据。

## 主要变化

- 概览页集中连接、路由模式和节点快捷面板；搜索、收藏、测速与完整代理组页面并存。
- 简易与标准界面共用订阅。简易界面收起高级入口，仍能展开使用；首次引导可关闭、重放。
- 全局直连例外支持应用预设、进程和网站。默认关闭，仅在全局模式生效，不覆盖规则模式的订阅规则。
- 订阅更新与本地修改分别保存；冲突保留旧配置并展示差异。过期编辑草稿不会直接覆盖更新后的配置。
- CFW 迁移助手读取配置快照、转换常见 YAML Mixin，并报告旧脚本兼容问题；不会自动执行旧脚本。
- 网络信息保留原有查询、城市、时区、ISP、ASN、延迟等功能，仅剔除坐标，并加入说明。
- 本地/WebDAV 备份默认使用独立密码加密；WebDAV、Gist、自定义托盘脚本默认关闭，单独启用。
- 代理终端、订阅请求头、监听地址、系统代理、TUN、DNS、嗅探、外部资源、Sub-Store、日志等高级入口保留。
- 内置主题与个人主题保留；在线主题由统一账号发布，格式检查后公开，支持网页收藏、举报和后台下架。主题提供颜色、系统字体、圆角、纯色及渐变背景，不接受可执行脚本。
- 客户端自动检查更新，用户确认下载；下载校验大小与 SHA-256。当前便携版由用户退出后解压替换，不覆盖正在运行的程序。

## 本机数据与升级

便携数据位于程序同级的 `DEX-STUDIO-NEXT` 文件夹；没有改用或覆盖原 Clash Party/CFW 的数据目录。升级前退出旧 Navio，将该数据文件夹复制到新版程序旁，可保留本机配置。首次连接默认系统代理，TUN 按需开启；首次默认不开机启动、不自动连接。

登录凭据通过 Windows 本机安全存储保护，不包含在普通配置备份中。独立备份密码与 D.E.X 登录密码不同，丢失备份密码将无法解密已导出的加密备份。恢复配置不会自动启用代理、TUN、WebDAV 或 Gist。

## 本预览版的明确边界

- 独立 Windows TUN 后台服务尚未实现。当前保留管理员方式启用 TUN；本次没有安装服务，也没有实测提权后的真实 TUN 流量。
- 邮箱验证码、短信与 Google/GitHub 的代码入口已接通；实际供应商验证需要服务器正式配置。短信采用 HTTPS 网关适配，不能直接把阿里云密钥填到客户端。
- 网站采用四个新增子域名，保留现有盲盒 API 和官网。尚未修改线上 Caddy 或 DNS；本机没有 Docker，镜像构建需在阿里云执行验证。
- 主题背景当前支持纯色和渐变，尚不提供图片素材上传托管。
- CFW 迁移不是旧版 JavaScript 与 Premium 特性的全自动兼容。迁移报告会列出需调整项目。
- 本次是便携调试版，未做 Windows 代码签名与自动安装。关于页只显示 Navio、版本和 Built by D.E.X Studio，完整来源在“鸣谢与开源许可”中。

详细测试范围见随包验证记录。完整功能确认清单仍保留；上述未完成事项不会被视为从需求中删除。
