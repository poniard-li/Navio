Navio — Windows 使用说明
Built by D.E.X Studio · Windows x64

发布与运行
从 https://github.com/poniard-li/Navio/releases 获取与版本对应的完整程序和源码。
安装版：运行 setup.exe，按提示选择安装目录。安装前请从托盘退出正在运行的 Navio；不要选用旧版免安装程序所在目录。
安装器会使用 Windows 临时目录解压，通常位于 C 盘。即使安装到其他盘，临时盘也需要足够空间；空间不足或文件校验失败时，请按提示处理后重新安装。
免安装版：解压完整 portable.zip 后运行 Navio.exe，不要只移动 exe。
账号 API 默认使用 https://navio.mydex.top。注册、登录、找回密码和账号管理均在软件内完成。

账号与离线使用
首次使用必须注册或登录 D.E.X 账号。软件支持用户名/邮箱/手机号加密码登录，以及邮箱/手机号验证码登录。注册验证一个邮箱或手机号；忘记密码时，在软件登录页选择“忘记密码”，验证已绑定联系方式后设置新密码。
Google/GitHub 登录和绑定在系统浏览器完成第三方授权，随后回到软件；首次使用第三方身份时，在软件补充 D.E.X 用户名及必要的联系方式验证。软件不会收集 Google 或 GitHub 密码。
设置 → 账号中可以修改昵称和密码、更换联系方式、绑定/解绑第三方账号、退出登录设备、撤销应用授权。退出当前设备后需要联网重新登录。
已成功登录的设备在账号服务暂不可用时可以离线使用本机代理、订阅配置与已保存的主题。账号被服务器停用或会话撤销后，下次联网验证需要重新登录。

账号服务器处理账号资料、验证码、第三方身份、主题与收藏等功能，不提供代理线路，不接收订阅链接或节点凭据。用户仍需自行导入订阅。D.E.X 官方云不备份订阅或节点凭据。
普通新用户注册、验证码登录与找回密码需要实际可用的邮件或短信提供商。Google/GitHub 按钮在服务端配置该提供商后启用。服务部署尚未完成时，客户端无法向默认域名注册。

主题与更新
主题工坊保留内置、本地设计与在线主题。在线作品与收藏入口可以搜索、收藏、举报、下载应用主题，以及查看和删除自己的在线发布；删除在线发布不删除本机主题文件。
新主题通过格式检查后公开；管理员可以处理举报和下架。已下架主题显示原因，作者保存修改后提交复核，由管理员确认后恢复公开。
支持颜色、系统字体、圆角、纯色、渐变、图片和视频背景。视频需要静态封面，始终静音，在窗口隐藏或关闭动画时暂停。媒体下载后可离线使用，导出主题包时一并保存。不接受可执行主题脚本。
软件自动检查公测更新，由用户确认后下载；校验大小与 SHA256 后，再确认退出更新并自动重启。安装版使用 EXE 安装到原目录，保留用户配置；免安装版替换程序目录并保留相邻的原版本备份。更新期间连接暂时中断。
0.6.0-beta.5 及更早版本首次升级到本版仍需手动安装或解压，之后可使用新更新流程。后台发布时需要分别提供安装版 EXE、免安装版 ZIP，不可混用。

本机数据与功能
安装版数据位于 %APPDATA%\DEX-STUDIO-NEXT，卸载时保留。免安装版数据位于程序旁的 DEX-STUDIO-NEXT；升级时将它复制到新版解压目录即可保留设置，原目录可留作备份。
从免安装版切换到安装版时，可以使用本地备份导出和恢复配置；备份不含登录凭据，需要重新登录。不要将旧数据直接覆盖到已有的账号数据目录。登录凭据受 Windows 本机安全存储保护。
概览页提供连接、模式切换和节点快捷面板；简易模式收起高级选项，标准模式完整显示，两者共用配置。首次默认不开机启动、不自动连接。
托盘 N 标识会随状态变色：灰色为默认状态，绿色表示系统代理已开启，蓝色表示 TUN 已开启，红色表示内核异常。鼠标悬停可查看模式、开关和内核状态；尚未确认的开关会单独注明。这些状态不代表节点或目标网站一定可用。
全局直连例外默认关闭，只在全局模式生效。网络信息保留原查询能力，仅去除坐标。订阅更新与本地修改分别保存，并提供差异与冲突处理。
订阅冲突按项目选择保留本地或采用订阅内容，确认前保留原配置。节点异常时只从当前策略组推荐，优先测速通过的收藏节点，再按延迟排列；需要用户确认后切换。
高级功能包括 CFW 迁移助手、代理终端、DNS、TUN、嗅探、外部资源、Sub-Store、日志、本地备份、WebDAV 和 Gist。WebDAV、Gist 和托盘脚本默认关闭；本地与 WebDAV 备份默认使用独立备份密码加密，丢失该密码无法解密旧备份。
配置引用数据目录之外的文件时，备份前列出路径，由用户确认纳入。已确认范围会保留，新路径不会自动获准。恢复时将文件放入受管理目录并改写相应引用，不覆盖原始外部文件。

TUN 后台服务
首次启用 TUN 可选择安装本机后台服务，或仅本次以管理员方式运行。安装服务需要 Windows 管理员授权，之后界面以普通权限运行。TUN 设置可查看状态、安装和卸载服务。
删除免安装程序目录不会移除已安装的服务；可在 Windows“已安装的应用”中卸载 Navio TUN Service。内核版本变化时，按软件提示更新后台服务。
服务只接受受支持的配置和受管理资源；不支持的配置会给出提示，可改用本次管理员运行方式。真实网络和系统服务安装需在目标 Windows 环境验证。

统一账号与恢复
同一 Windows 用户下，已接入的 D.E.X 软件可提示“以此账号继续”，用户确认后建立独立会话，也可切换账号。共享凭据经本机加密，按账号服务区分。
失去全部登录方式时，联系管理员核实身份并取得恢复凭据，在软件内验证新邮箱或手机号并设置新密码。只替换对应类型的联系方式，其他绑定和业务数据保留。
旧盲盒账号绑定需分别验证双方身份并确认。原积分、订单和权益留在旧账号；旧盲盒桌面客户端的统一账号入口仍需单独接入。
来源与许可请查看软件内“鸣谢与开源许可”，以及 LICENSE、DEX-THIRD-PARTY-NOTICES.txt。对应测试范围见 Navio-验证记录.txt。

规则数据库
公开分发包不附带历史 GeoIP / ASN / GeoSite / BundleMRS 数据。内核尚未启动时，可在“外部资源 → 下载最新数据库”中获取当前数据，默认来源是 MetaCubeX 的 GitHub 数据发布，请求不包含订阅或节点凭据。内核运行时，请使用内核的数据更新功能。
依赖缺失数据库的规则可能无法启动。下载失败时，检查网络和资源地址后重试；下载成功后按需重启内核。下载操作不会开启系统代理。
