Navio 0.6.0-beta.1 · Public Beta（公测版）
Built by D.E.X Studio · Windows x64 免安装版

发布与运行
从 https://github.com/poniard-li/Navio/releases 获取与版本对应的完整程序和源码。
解压整个程序目录后运行 Navio.exe，不要只移动 exe。账号 API 默认使用 https://navio.mydex.top；Navio 没有面向普通用户的产品网站或账号门户。管理员入口与普通账号功能分开，软件用户不需要访问管理后台。

账号与离线使用
首次使用必须注册或登录 D.E.X 账号。软件支持用户名/邮箱/手机号加密码登录，以及邮箱/手机号验证码登录。注册验证一个邮箱或手机号；忘记密码时，在软件登录页选择“忘记密码”，验证已绑定联系方式后设置新密码。
Google/GitHub 登录和绑定在系统浏览器完成第三方授权，随后回到软件；首次使用第三方身份时，在软件补充 D.E.X 用户名及必要的联系方式验证。软件不会收集 Google 或 GitHub 密码。
设置 → 账号中可以修改昵称和密码、更换联系方式、绑定/解绑第三方账号、退出登录设备、撤销应用授权。退出当前设备后需要联网重新登录。
已成功登录的设备在账号服务暂不可用时可以离线使用本机代理、订阅配置与已保存的主题。账号被服务器停用或会话撤销后，下次联网验证需要重新登录。

账号服务器处理账号资料、验证码、第三方身份、主题与收藏等功能，不提供代理线路，不接收订阅链接或节点凭据。用户仍需自行导入订阅。D.E.X 官方云不备份订阅或节点凭据。
普通新用户注册、验证码登录与找回密码需要实际可用的邮件或短信提供商。Google/GitHub 按钮在服务端配置该提供商后启用。服务部署尚未完成时，客户端无法向默认域名注册。

主题与更新
主题工坊保留内置、本地设计与在线主题。在线作品与收藏入口可以搜索、收藏、举报、下载应用主题，以及查看和删除自己的在线发布；删除在线发布不删除本机主题文件。
主题通过格式检查后公开；管理员可以处理举报和下架。支持颜色、系统字体、圆角、纯色和渐变背景，不接受可执行主题脚本，暂不托管背景图片。
软件自动检查公测更新，用户确认后下载 GitHub 更新包；下载支持 HTTPS 跳转，仍检查文件大小与 SHA-256。退出 Navio 后，将新版本解压到新目录再运行。

本机数据与原有能力
便携数据位于程序旁的 DEX-STUDIO-NEXT。升级前退出旧程序，将该数据目录复制到新程序旁，可保留本机设置。登录凭据受 Windows 本机安全存储保护，不包含在普通配置备份中。
概览页提供连接、模式切换和节点快捷面板；简易模式收起高级选项，标准模式完整显示，两者共用配置。首次默认不开机启动、不自动连接。
全局直连例外默认关闭，只在全局模式生效。网络信息保留原查询能力，仅去除坐标。订阅更新与本地修改分别保存，并提供差异与冲突处理。
CFW 迁移助手、代理终端、DNS、TUN、嗅探、外部资源、Sub-Store、日志、本地备份、WebDAV、Gist 等入口继续保留。WebDAV、Gist 和托盘脚本默认关闭；本地与 WebDAV 备份默认使用独立备份密码加密，丢失该密码无法解密旧备份。

当前范围
Windows 独立 TUN 后台服务尚未实现，当前使用管理员方式的备用路径；没有将这点视为从需求中删除。真实 TUN、正式邮件/短信/OAuth、代码签名与安装包还需对应环境验证。
来源与许可请查看软件内“鸣谢与开源许可”，以及 LICENSE、DEX-THIRD-PARTY-NOTICES.txt。对应测试范围见 Navio-验证记录.txt。


0.6 公开分发包不附带历史 GeoIP / ASN / GeoSite / BundleMRS 数据。在“外部资源 → 下载最新数据库”中按需获取当前数据，默认从 MetaCubeX 的 GitHub 数据发布下载；这些请求不包含订阅或节点凭据。内核未启动也能下载。依赖缺失数据的规则可能暂时无法启动，网络不可达时需检查资源来源后重试。下载成功后按需重启内核；下载失败不会开启系统代理。原有内核数据更新功能仍保留。
