Navio 0.4 功能预览版 · 由 D.E.X Studio 开发

启动与改名
解压 Windows-x64 压缩包，运行 Navio.exe。首次启动选择标准模式或简易模式，再进入操作引导。
开发者署名与产品名称已经分开。为兼容上个预览版，内部配置目录 DEX-STUDIO-NEXT 和 dexstudio:// 协议保持稳定，不把显示名称当作数据目录。
便携版本的设置在程序旁 DEX-STUDIO-NEXT 文件夹中。升级便携版本时，请关闭旧版，将你自己的该文件夹复制到新程序旁；请保留原文件夹作为备份。发布包不包含测试订阅或用户配置。

全局代理下的直连例外
在「直连例外」中启用需要的应用或网站，常见应用可从内建清单选择，也可自行添加。
普通 Mihomo global 模式不匹配路由规则。Navio 的“全局 + 例外”由规则模式执行：匹配清单 → DIRECT，其余 → GLOBAL 中所选线路。界面保留你的全局意图并显示例外状态；这是客户端生成配置，没有修改内核。
关闭例外会恢复普通全局模式。规则模式仍遵循订阅自己的规则；直连模式本身就全部直连。
直接联网的网站会看到本地网络的公网出口 IP，而不是代理出口。内建域名清单只覆盖已列出的域名，不承诺覆盖一款软件的所有关联服务。进程名可能随软件更新改变；程序流量需要进入内核，且内核能够识别进程才能匹配。可以从连接页核对实际进程与规则命中。
修改作用于新连接；已有连接可能需要在应用内重新连接。遇到不遵循系统代理的软件，可按需配置 TUN；本版不会因为选择直连例外就自动打开 TUN。

初次使用与界面模式
标准模式保留完整订阅与专业设置。简易模式使用可视化配置流程，导航优先显示常用功能；“更多功能”可展开专业入口。
首次选择及引导完成/稍后学习状态保存在本机。设置 → 通用 → 使用指南可重新查看；设置 → 通用也可切换模式。
切换模式会重新加载相应配置，不只是外观切换。引导不自动打开系统代理、TUN 或局域网访问。
提前关闭引导会说明代理范围、直连例外等设置对连接与出口地址的影响，并提供继续学习或稍后学习。不会用夸大的风险话术阻拦关闭。

功能解释
外部资源：配置引用的节点集合和规则集合。通常随订阅维护，不需要为了正常上网逐个编辑。
嗅探覆写：从协议可见信息补充目标域名，帮助域名分流。并非解密 HTTPS 正文；“覆写”表示客户端设置替换订阅对应部分。
Sub-Store：合并订阅、筛选/重命名节点、转换格式的工具。单订阅能正常用时可不启用。远程转换服务可能接触带凭据的订阅链接；应选择可信来源。
内核设置：管理承担协议、DNS、路由和转发的后台内核，重启/换核会影响现有连接。
Smart：Mihomo 扩展分支中的智能选点策略，可参考连接表现并使用可选 LightGBM 模型。它不是聊天 AI，不保证总比稳定版更快。模型可能需要下载；训练数据收集可保持关闭。日常默认使用稳定版。
以上说明可在软件「使用指南」中搜索；复杂功能旁的帮助可用鼠标悬停、点击或键盘焦点查看。

网络信息与隐私
移除经纬度坐标和精确位置显示；第三方返回的坐标、城市、时区等字段不再进入界面状态。
公网查询与延迟检测改为主动点击触发，切换查询服务本身不发送查询。公网 IP 默认遮盖。
公网 IP 是网站看到的出口地址。ISP 是互联网服务商或出口机房，ASN 是网络组织的路由编号，两者通常由大量用户共享，本身不是个人身份或 GPS 坐标。
查询第三方服务时，它会看到请求的公网出口 IP；数据库归属信息可能不准确。软件不读取 GPS 或请求精确位置权限。这不等于互联网请求不会留下任何记录。
手动测速也会访问所列测试目标。分享网络页、连接页或日志截图之前，请检查敏感 IP、域名及订阅凭据。

内核与“原神”
Mihomo 官方中文 Wiki 的“虚空终端”“基于原神”文案确实存在。对照官方源码和功能说明，它实际是 Go 编写的网络代理内核；将相关游戏文案理解为社区玩梗是基于这些材料的判断，不是游戏技术依赖。

后续维护建议
Navio 保持独立的产品设计与客户端逻辑，当前固定 Mihomo v1.19.32 稳定内核。后续可以维护有明确补丁、自有构建和上游同步流程的内核分支；需要保留上游出处并遵守对应开源许可，不能称为从零原创内核。
从零开发内核需要长期维护代理协议、DNS、防泄漏策略、TCP/UDP、TUN、系统路由与跨平台行为。目前这些产品需求能够在客户端层实现，不建议为了品牌独立立刻放弃成熟内核。

当前范围
此交付为 Windows x64 便携预览版。主题工坊及原专业功能保留。账号服务尚未新增，主题服务器仍按此前手动部署方式提供，未自动操作阿里云。
实际验证范围见同目录验证记录。真实机场订阅、微信/抖音当前版本的所有流量、TUN/管理员权限、开机自启动等需要在相应环境继续验收。
